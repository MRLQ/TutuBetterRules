# TutuBetterRules

**TutuBetterRules** 는 대표적인 프록시 클라이언트를 위한 깔끔하고 체계적인 트래픽 관리를 제공하도록 설계된 다중 플랫폼 규칙·설정 모음입니다.  
모든 규칙은 세심하게 선별·지속적으로 업데이트되며 완전 무료입니다—도움이 되었다면 ⭐ 한 번 눌러 주세요!

> **알림 채널**  
> 업데이트 및 점검 소식을 실시간으로 받으려면 Telegram: [@hututu00](https://t.me/hututu00) 팔로우

## 1 프로젝트 하이라이트

| 특징 | 설명 |
|------|------|
| **광범위한 지원** | 데스크톱·모바일·라우터용 선도 클라이언트의 즉시 사용 가능한 설정 제공 |
| **자체 인프라** | 자가 호스팅 구독 변환/단축 링크 서비스로 개인 정보 보호 및 누수 방지 |
| **의도적인 프리셋** | 광고 차단, 미디어 트래픽 분리, 로컬 서비스 존중—대부분 사용자에게 바로 적합 |
| **오픈·감사 가능** | 모든 규칙이 GitHub에서 버전 관리되어 직접 검토·포크·기여 가능 |
