# TutuBetterRules

**TutuBetterRules** is a cross-platform rule set and configuration collection designed to deliver clean, structured traffic management for popular proxy clients.  
All rules are meticulously curated, continuously updated, and provided free of charge—just remember to leave a ⭐ if you find the project helpful!

> **Notification channel**  
> Stay informed about updates and maintenance windows via Telegram: [@hututu00](https://t.me/hututu00)

## 1 Project Highlights

| Feature | Description |
|---------|-------------|
| **Comprehensive coverage** | Ready-to-use configurations for leading clients on desktop, mobile, and router platforms. |
| **First-party infrastructure** | Self-hosted conversion and short-link services keep your subscription data private and leak-proof. |
| **Opinionated presets** | Practical defaults that block ads, segment media traffic, and respect local services—ideal for most users out-of-the-box. |
| **Open & auditable** | Every rule is version-controlled on GitHub so you can review, fork, or contribute. |
