# TutuBetterRules

**TutuBetterRules** مجموعه‌ای از قوانین و پیکربندی‌های چندسکویی است که برای مدیریت ترافیک به‌صورت شفاف و ساخت‌یافته در کلاینت‌های پراکسی محبوب طراحی شده است.  
تمام قواعد با دقت بالا انتخاب و به‌صورت پیوسته به‌روزرسانی می‌شوند و کاملاً رایگان در دسترس‌اند—اگر مفید بود، یک ⭐ یادتان نرود!

> **کانال اعلان‌ها**  
> برای دریافت به‌روزرسانی‌ها و اطلاعیه‌های نگه‌داری، ما را در تلگرام دنبال کنید: [@hututu00](https://t.me/hututu00)

## 1 ویژگی‌های برجسته

| قابلیت | توضیح |
|--------|-------|
| **پوشش جامع** | پیکربندی‌های آماده برای کلاینت‌های پیشرو در دسکتاپ، موبایل و روتر. |
| **زیرساخت اختصاصی** | سرویس‌های تبدیل اشتراک و کوتاه‌کننده لینک به‌صورت خود میزبانی، با احتمال نشت صفر. |
| **پیش‌تنظیم‌های هدفمند** | پیش‌فرض‌های عملی برای مسدودسازی تبلیغات، جداسازی ترافیک رسانه‌ای و احترام به خدمات محلی. |
| **متن‌باز و قابل حسابرسی** | تمام قوانین در GitHub نسخه‌بندی شده و قابل بررسی، فورک یا مشارکت هستند. |
