# TutuBetterRules

**TutuBetterRules** 是一套跨平台分流规则与配置合集，旨在为主流代理客户端提供整洁、有序的流量管理方案。  
全部规则精心打磨、持续更新，完全免费使用——觉得有帮助就顺手点个 ⭐ 吧！

## 1 项目亮点

| 特性 | 说明 |
|------|------|
| **覆盖面广** | 提供适用于桌面、移动端与路由器的主流客户端现成配置。 |
| **自建基础设施** | 自托管的订阅转换与短链服务，确保订阅数据私密且零泄漏。 |
| **开箱即用** | 默认集成广告屏蔽、媒体分流、本地服务直连，大多数用户无需改动即可使用。 |
| **公开可审计** | 所有规则在 GitHub 版本控制，可自由复刻、审阅或提交 PR。 |
