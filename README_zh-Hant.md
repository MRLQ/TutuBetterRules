# TutuBetterRules

**TutuBetterRules** 是一套跨平台規則與配置集合，為主流代理客戶端帶來乾淨、有序的流量管理。  
所有規則均經精心挑選並持續更新，完全免費——若覺得有幫助，請順手點顆 ⭐！

## 1 專案亮點

| 特性 | 說明 |
|------|------|
| **覆蓋範圍廣** | 提供桌面、行動裝置與路由器主流客戶端的現成配置。 |
| **自建基礎設施** | 自託管訂閱轉換與短鏈服務，確保訂閱資料私密且零外洩。 |
| **開箱即用** | 預設整合廣告阻擋、媒體分流、本地服務直連，多數使用者無需修改即可使用。 |
| **公開可稽核** | 所有規則於 GitHub 版本管理，可自由分叉、審閱或貢獻。 |
